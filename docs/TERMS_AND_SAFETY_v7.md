# QMR Proxy — terms and safety v7

QMR Proxy is a directory of third-party Telegram MTProto connection links, not a privately owned network or VPN. Its publicly listed sources may change, be blocked, degrade, or inject promoted channel banners. QMR7S cannot control such third-party promotions.

Users should not share login codes, passwords, 2FA passcodes or personal information with any proxy operator. Proxy operators may see connecting IP addresses and times; using MTProto only affects Telegram's connection and does not anonymize all traffic.

The bot checks @QMR7S membership via Telegram and may store basic usage metadata (user ID, usage timestamps and message counts) when its database is active. The Mini App's personally saved proxy links are stored in browser localStorage, not sent to the bot. The site may have hosting logs outside the control of this source code. User data deletion: /delete_my_data for the bot record and clear browser storage for local proxy links.

The bot requires subscription to @QMR7S to open community link lists, but the public PWA is separately accessible and does not enforce the same gate. For support contact @QMRSupportbot.
