## Consolidation

The separate v12.5 source bundle contains 50 reference files assembled from the prior release archives and a local audit/SQLite backup utility. This review branch documents the baseline; it is NOT the complete source bundle, a deployable replacement, or a migration of the legacy native runtime.

## Deployment gates

1. Compare the active installation to the reference source manifest. Do not overwrite unexpected files.
2. Produce a consistent SQLite online backup and verify integrity. Keep private history and credentials outside GitHub. Never commit SQLite, .secrets, logs, local runtime reports or bot tokens.
3. Select a host with persistent storage and stable HTTPS. Free ephemeral filesystem hosting is not a fit for unchanged SQLite architecture.
4. Validate the complete source and migration offline, including public and Mini App routes, owner authorization, queue durability, and rollback. Named-tunnel hostname support requires explicit allowlist and verifier updates before migration.
5. Only then perform an authorized cutover, keeping pending Telegram updates and allowing exactly one active consumer. No automated webhook change during an outage. Keep the current working installation until verification succeeds.

No live hosting change, native serverless deployment, Sites update or main-branch merge is performed by this document.
