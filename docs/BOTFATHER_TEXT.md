## Short Description (About)
QMR Proxy | روابط MTProto متجددة • قناة @QMR7S • دعم @QMRSupportbot

## Description
QMR Proxy من QMR7S — بوت تفاعلي يعرض روابط MTProto العامة المتجددة، مع قوائم منظمة، وطريقة اتصال مبسطة، وإرشادات للخصوصية والحظر. تتبع الروابط مشغّلين خارجيين، وقد تظهر قنوات ترويجية؛ لا نقدم ضماناً للسرعة أو الأمان أو الوصول من العراق. قناة التحديثات: @QMR7S، والدعم: @QMRSupportbot.
