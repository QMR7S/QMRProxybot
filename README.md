# QMR Proxy

Repository bootstrap for QMR Proxy. The running Telegram bot, Telegram Serverless, website hosting, proxy servers, webhook, and external databases are **not deployed or modified** by this commit.

Development is staged on a review branch and must be tested before any production deployment. No tokens, CLI credentials, or user data belong in Git.

See the upcoming review pull request for the QMR Proxy v2 integration and deployment checklist.
